Em produção, cada adega deve usar fotos próprias, fornecidas pelo estabelecimento, pelo fabricante/distribuidor com autorização, ou material licenciado para uso comercial. O ADEGA PRO não deve copiar automaticamente imagens de resultados do Google para armazenamento permanente.
